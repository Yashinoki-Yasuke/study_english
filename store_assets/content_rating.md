# コンテンツレーティング質問票 回答方針

Play Console「アプリのコンテンツ」→「コンテンツのレーティング」で、
IARC（国際年齢レーティング連合）の質問票に回答するとレーティングが自動算出される。
本アプリ（英単語・熟語の学習、クイズ、リスニング機能のみ）は、
以下の質問項目すべてで「いいえ／なし」と回答して問題ない。

## 想定される質問と回答

| 質問カテゴリ | 回答 |
|---|---|
| 暴力表現 | なし |
| 性的表現・ヌード | なし |
| 下品な言葉・不適切な言葉 | なし |
| 恐怖表現 | なし |
| 危険行為の描写（薬物・アルコール・タバコ等） | なし |
| ギャンブル表現・シミュレーション | なし |
| ユーザー生成コンテンツ（投稿・チャット等） | なし（本アプリにSNS的機能は無い） |
| 他のユーザーとの交流（チャット、フレンド機能等） | なし |
| 位置情報の共有 | なし（位置情報の権限を要求していない） |
| 個人情報の共有 | なし |
| デジタルコンテンツの購入 | なし（現状、課金機能・アプリ内購入は無い） |

上記の通り「該当なし」で一貫しているため、想定されるレーティングは
**全年齢対象（例: IARC 3+ / ESRB Everyone 相当）** になる見込み。

## 注意点

- 広告（AdMob）が表示されるアプリであること自体は、レーティングの
  加点対象ではないが、別途「広告を含む」の申告欄（コンテンツレーティングとは
  別セクション）で必ず「はい」と回答すること。
- 質問票の文言はGoogle側で更新されることがあるため、実際の画面の文言に
  沿って回答すること（本ファイルは方針の下書き）。
